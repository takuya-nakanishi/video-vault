# Query — 問いに答える

agent-base の雛形(`templates/skills/query/`)から写したもの。写したあとはこのリポジトリのもので、工程を足したり書き換えたりしてよい。この skill は工程だけを決める。

- **先に読む**: `llm-wiki` skill(全リポジトリ共通の作り)と、直下の `AGENTS.md`「LLM Wiki」(このリポジトリの事情)。
  食い違ったら規約が正(規約どうしでは直下の `AGENTS.md` が優先)
- `AGENTS.md`「LLM Wiki」が追加の手順(この skill のディレクトリに置いた追加のファイルなど)を指していれば、該当する工程の前に読む
- このリポジトリの事実(原本の置き場・読み方・章立て・コミットの先など)は `AGENTS.md`「LLM Wiki」に書く。手順そのものを変えるときは、この SKILL.md を直す

## 工程

0. **最新にする。**`git pull --rebase`(書き戻すと決まってからでは、作業ツリーが汚れていて取り込めない)。始める前の手順(worktree・ロックなど)が `AGENTS.md`「LLM Wiki」にあれば、それに従う
1. **`llm-wiki/wiki/index.md` を読み、当たるページを決める。**全ページは読まない。用語が分からなければ用語集、どこにあるか分からなければ `grep -rn '語' llm-wiki/wiki/`
   - 確定した設計・仕様・手順を問われたら、Wiki ではなく確定した文書の置き場(`AGENTS.md`「何を貯めるか」)を読む(Wiki はそれを写さない)
   - 問いを起点に調べるときは `node scripts/wiki/open-questions.mjs <語>` で関わる問いを出す
2. **当たるページを読む。**足りなければ、そのページの frontmatter の `sources` にある要約ページへ降りる。それでも足りなければ原本(台帳 `llm-wiki/raw/manifest.tsv` か `llm-wiki/raw/`)へ降りる
3. **答える。**
   - 結論を先に書き、根拠にしたページへのリンクを節まで付ける(`[[wiki/concepts/名前#見出し|名前]]`)。確定した文書へは相対パスの Markdown リンク
   - Wiki に書いていないことは「Wiki に無い」と言い、一般の知識で補うなら分けて書く。自分の解釈には **推測:** と付ける
   - ページどうし、またはページと確定した文書が食い違っていたら、両方を示す(仕様は確定した文書が正)
   - 費用・規約など変わりうる事実は、Wiki に書いた時点を添えて答える
   - 当たったページの「未解決の問い」に触れたら、まだ分かっていないと伝え、Q の ID を添える
   - 複数のページをまたいで組み立てた答えには、`visual-explain` skill に従って図を添える(図の書き出しに根拠のページへのリンクを付け、`inquiries/` に保存するときは図ごと保存する)
4. **書き戻す。**人に聞かずに行い、終わったら何をしたかを伝える(git の履歴に残るので戻せる)
   - **既存のページへ**: 答える中で分かった新しい事実・ページどうしのつながりを、関わるページへ足す。足した記述には出典(保存した `inquiries/` のページ、または根拠の要約ページ)を付ける
   - **`inquiries/` へ保存するか**: 比較・判断の材料・切り分けの手順・複数のページをまたいで組み立てた答え・原本まで降りて分かった事実は保存する。
     単純な事実の確認、1 ページで済んだ答えは保存しない。書き方は `llm-wiki` skill(`type`・`asked`・`sources`・`updated`。起点の問いは書き換えない)
   - 保存したら、根拠にしたページから保存したページへもリンクを張り返す
   - 既存の記述の誤りに気づいたら、`llm-wiki` skill「誤りと対立」の書式で訂正する(連鎖も含めて)
5. **問いを直す。**書き方と閉じ方は `llm-wiki` skill「未解決の問い」と `questions-jobs` skill
   - 答えが出て既存の問いが解けたら、本文に書いて閉じる
   - 答えられなかった点、答える中で新しく分かった未知は、人に断らずに起票し、終わったら伝える。項目のファイルに `ページ:` を書く
   - 「〜する必要がある」「〜が未着手」は問いではなく作業。`llm-wiki/backlog/JOBS.md` へ起票する
   - 問いを触ったら `node scripts/wiki/open-questions.mjs --write` で各ページの「未解決の問い」を作り直す
6. **コミットする。**書き戻した・保存した・問いを触ったときだけ。`node scripts/wiki/lint.mjs` がエラー 0 になってから、
   触ったファイルをパスを明示してコミットし、push する。コミットの先と件名の接頭辞は `AGENTS.md`「コミット」。
   本文は `llm-wiki` skill「履歴(git)」(問いの要約と、書き戻した・保存したもの)

## 終わったら人に返すもの

- 答え(結論・根拠のリンク・推測と分からないこと)
- 書き戻したページ・保存したページ・訂正
- 起票した問い・作業と、閉じた問い
- 足りない原本と、確かめ方
